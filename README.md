# Dash & Dandy — demo website

A responsive one-page concept for Dash and Dandy Dog Grooming in Clowne.

## Local preview

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:4173`.

## Checks

```bash
npm test
```

The production-ready static site is in `dist/` and is deployed to GitHub Pages by the included workflow.
